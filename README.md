# YouTrain — trial build

A clickable trial of the YouTrain app concept (coach avatar, honest timelines, levers, food/workout logging mock).

- Open the URL on your phone → tap Share → Add to Home Screen → it installs as an app icon.
- Everything you enter stays **on your own device** — this build has no server and sends nothing anywhere.
- Mock data is estimates you can edit; the real build adds generated dream-you + real pose checks.
